📌 Project Overview

This project focuses on analyzing customer churn behavior and revenue impact using real-world business metrics.
The dashboard helps identify churn drivers, high-risk customers, and revenue loss patterns to support data-driven retention strategies.

🎯 Project Objectives

Analyze customer churn trends

Identify high-risk customers

Measure revenue loss

Understand contract & tenure behavior

Support business decision-making

✔ Customers with more support tickets churn more
✔ Early-stage customers are at higher risk
✔ Revenue loss is concentrated among high-value users
